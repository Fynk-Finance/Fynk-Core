## What was done

  * Sofia chose to open that PR and start Step 5 at the same time. #7 was merged during the session, and this branch was rebased on it without conflicts.
* **Migrations.**
  * `internal/platform/migrate` runs golang-migrate v4.20.1 for one module at a time, in its own schema with its own `<schema>_migrations` table.
  * `internal/app/migrations.go` lists every module plus `audit` once.
  * `internal/audit/migrations` is a one-line hook for M13.
  * `cmd/migrate` offers `up` and `status`.
* **API image.**
  * `services/api/Dockerfile`: multi-stage build onto distroless nonroot, pinned by digest, holding two binaries (`/api` and `/migrate`).
  * `api healthcheck` subcommand, because the image has no curl.
* **Placeholders in other owners' folders.** Sofia approved minimal placeholders in each folder, for each owner to review:
  * M16: the bank simulator with a public `/healthz` and an internal mTLS listener that only accepts client certificates from the local CA and logs their serial;

  * M16: the `banco-demo` realm (one seeded customer);

* **`docker-compose.yml`.** Postgres 16.15, Redis 7.4.11, Keycloak 26.8.1, Mailpit, API, bank simulator and Caddy 2.11.7, plus the `migrate` and `certs` one-off services.
  * Seeded passwords come from `.env` through Keycloak's `${...}` placeholders.
  * Postgres and Redis listen on 127.0.0.1 only.
* **Certificates.** `scripts/dev/certs.sh` runs inside the pinned step-cli image (no host install) and writes the CA, Caddy, bank and client certificates to the gitignored `certs/`.
* **Makefile.** `dev`, `down`, `migrate` and `certs`.
* **Docs.**
  * `docs/local-dev.md`: tools, first run, ports, seeded users, checks, certificates, reset and troubleshooting.

* **Tests:**

  * the API healthcheck;
  * the bank mTLS handshake (no certificate, wrong CA, valid certificate, serial logged);

## Decisions and problems

* Images are pinned to versions that have been out for a few days. Redis 7.4.12 and Mailpit 1.32.0 were too new.
* Avast antivirus on this machine intercepts TLS even on 127.0.0.1 and swaps in its own certificate. The bank mTLS test therefore runs the TLS handshake in memory, so it passes on any machine. The problem is in the troubleshooting table.
* `make migrate` builds the API image first, so it works on its own. `migrate status` also creates empty schemas, because golang-migrate creates its table when it connects.
* Mailpit was added now (M1's prompt asks for it), so M1 does not need to edit M0's compose file later.
* To review with M1: their prompt names the redirect `co.fynk.app://oauth/callback`, but the app uses the `fynk` scheme. The placeholder uses `fynk://oauth/callback`.
